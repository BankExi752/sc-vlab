# 双创决策沙盘 —— 从商业画布→4P作战→计划书路演的算账闭环

虚拟仿真实验教学项目（创新创业教育 · 决策型虚拟仿真实验 · Streamlit V1.0）

依据《双创决策沙盘虚拟仿真实验方案 V3.0 完整版》实现：

- **26 步交互式仿真实验**：开局契约 → 选赛道/痛点/画像/市场 → 商业画布九格（卡片化）→
  4P作战（MVP取舍/定价滑块带市场基准/渠道预算/促销组合）→ 月度结算 → R1/R2/R3 风险事件博弈 →
  计划书补全（自动灌入骨架）→ AI 五维判定 → 虚拟路演+终评；
- **算账闭环四因子**：现金 / 客户数 / 毛利 / 路演与计划书质量分，每步操作实时刷新；
- **红线机制**：资金红线（现金≤0 且融资失败→破产）、合规红线（无资质经营→直接失败）、
  画布红线（价值主张空话且收入=0→不能进入4P）、路演红线（计划书无壁垒与风险→路演分封顶60）、
  刷分红线（复制粘贴套话→该模块重做）；
- **AI 双节点（本地规则引擎降级）**：逻辑裁判（画布与4P五维判定，只判定不代决策）+
  提分教练（计划书/路演五维判定+提分建议），接口异常时按硬编码权重公式兜底出分；
- **考核评价**：七模块 100 分制（决策过程A 20 + 决策过程B 20 + 画布逻辑 15 + 4P执行与一致性 15 +
  风险控制 10 + 计划书 10 + 路演 10），终局评定 优秀/合格/不合格；
- **全局易用性**：26 步进度导航、四因子仪表盘+月度走势图、同口径复盘表、
  20 个小白化词条、审计日志 CSV 导出、教师可导出成绩。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run main_app.py
```

## 部署

- GitHub 仓库 main 分支，Streamlit Cloud 自动部署绑定。
- 依赖仅 streamlit + pandas + plotly，无外部模型依赖；AI 判定由本地规则引擎完成（完全可离线）。

## 结构

- `main_app.py`：单文件应用（算账引擎纯函数 + 26 步 UI + 红线/风险/AI + 报告）
- `smoke_test.py`：引擎冒烟测试（四因子结算/画布逻辑分/4P一致性/AI判定/红线/评分）
- `test_apptest.py`：AppTest 端到端（跑通 26 步全流程）
- `requirements.txt`：运行依赖
